# 表单填写节奏

`OutlookController.outlook_register` 的邮箱、密码、生日和姓名步骤采用与 `outlook-re` v21 一致的人类化输入节奏：

- 文本字段逐字符发送 `keydown`/`keyup`，字符间使用随机延迟，并保留偶发停顿和回退重打。
- 表单元素点击包含随机的点击前、按下和点击后等待。
- 邮箱、密码、生日、姓名各阶段之间使用随机区间暂停。
- 月份和日期优先使用点击后键盘导航选择，原生 `select` 保留值选择兜底。

协议同意按钮前仍使用 `bot_protection_wait`；表单提交后的验证码、邮箱初始化和 OAuth 流程未改变。
